# Performance

Monthly P&L summaries from the live Alpaca account. Each file is named `YYYY-MM-summary.md` and contains:

- Cumulative P&L
- Monthly P&L
- Max drawdown from peak (intra-month)
- Sharpe ratio (running)
- Trade count
- Win rate
- Per-signal attribution (which signals drove the month's results)

## Cross-reference

Each month's summary links to:
- The corresponding Substack essay
- The Alpaca portfolio share link snapshot
- The trade journal export (CSV) where applicable

## Verifiability

Every claim in a performance summary should be reproducible by reading the public Alpaca portfolio share link. If you find a discrepancy, file an issue.
