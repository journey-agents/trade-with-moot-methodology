# Contributing

## Issues: open

If you spot a factual error, a methodology gap, a contradiction between this repo and the visible Alpaca trading record, or a question about how something works — **please open an issue**. This is the primary surface for community engagement with the methodology.

Issue templates:
- **Correction** — "page X claims Y but actually Z"
- **Question** — "what does X mean?" / "why this choice over Y?"
- **Methodology challenge** — "have you considered X failure mode?"

## Pull requests: closed

This is a single-author project. The methodology represents one operator's specific experimental setup. Pull requests are closed by design — they would dilute that.

If you have improvements, fork freely (the license is CC-BY-SA-4.0). Don't expect changes merged upstream.

## Code contributions

This repo contains documentation only. The trading bot's source code is in a private repo and is not accepting outside contributions.

## Code of conduct

Be useful, be skeptical, be kind. Bad-faith engagement (dunking, harassment, low-effort drive-bys) will be locked without comment.
